Core Business Definitions
User

A user means:

employee_id


For user analytics use:

COUNT(DISTINCT employee_id)

Device

A device means:

user_mac


For device analytics use:

COUNT(DISTINCT user_mac)

Valid User

Definition:

employee_id IS NOT NULL
AND total_success_count >= 1


This is the final definition.

UX Missing

Definition:

ux_available = false


A valid user may still be UX missing.

These concepts are independent.

Unmapped User

Definition:

employee_id IS NULL

Invalid Device

Definition:

employee_id IS NULL
AND total_success_count = 0
