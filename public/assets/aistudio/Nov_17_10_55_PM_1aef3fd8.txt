CRITICAL DATA MODEL DEFINITIONS

These definitions are mandatory.

USER

A user means:

Plain Text
employee_id

All user-level metrics use:

SQL
COUNT(DISTINCT employee_id)

Never count MAC addresses for user metrics.

DEVICE

A device means:

Plain Text
user_mac
 

All device metrics use:

SQL
COUNT(DISTINCT user_mac)
VALID USER

A valid user is:

SQL
employee_id IS NOT NULL
AND total_success_count >= 1

A valid user may still have:

SQL
ux_available = false

This is intentional.

UX verification does NOT determine validity.

UX MISSING

Defined as:

SQL
ux_available = false
 

This is a data-enrichment condition.

Not a user validity condition.

UNMAPPED USER

Defined as:

SQL
employee_id IS NULL
INVALID DEVICE

Defined as:

SQL
employee_id IS NULL
AND total_success_count = 0
EVENT ENRICHMENT REQUIREMENT

wifi_event_history DOES NOT contain:

Plain Text

SQL

Do not attempt to read those fields directly from wifi_event_history.
