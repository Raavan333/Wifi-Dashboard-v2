Core Business Definitions

These definitions are mandatory.

USER

A user is:

employee_id


All user level analytics must use:

COUNT(DISTINCT employee_id)


Never use:

COUNT(DISTINCT user_mac)


for user metrics.

DEVICE

A device is:

user_mac


Device metrics use:

COUNT(DISTINCT user_mac)


Example:

Employee 1851960

MAC-A
MAC-B
MAC-C


dashboard must return:

Total Users = 1

Total Devices = 3

VALID USER

A user is considered VALID when:

employee_id IS NOT NULL
AND total_success_count >= 1


Rationale:

User can be valid even if:

ux_available = false


because UX verification is independent from identity validity.

UX MISSING

Defined as:

ux_available = false


This is NOT an invalid user.

It is a data enrichment condition.

UNMAPPED USER

Defined as:

employee_id IS NULL

INVALID DEVICE

Defined as:

employee_id IS NULL
AND total_success_count = 0


unless a better business rule is provided later.

RECOVERY DEFINITION

Recovery is NOT:

fail exists
and
success exists


Recovery MUST mean:

FAIL event
followed later by
SUCCESS event

for same user_mac


Time ordering matters.

Example:

10:01 FAIL

10:03 FAIL

10:05 SUCCESS


Recovered.

Example:

10:01 SUCCESS

10:10 FAIL


Not recovered.
